# JanSahay React + Vite Frontend Application

This is the React frontend for JanSahay — Government Scheme Discovery & Citizen Services Platform.

## Features
- **Trilingual Support**: English, Hindi (हिंदी), and Bengali (বাংলা) language context switcher.
- **Scheme Discovery**: Filter schemes by category, state, and beneficiary group.
- **Official Portal Guarantee**: Direct links to genuine `.gov.in` application forms.
- **Smart Eligibility Wizard**: Step-by-step evaluator matching user profile to welfare schemes.
- **Public Grievance Tracker**: Real-time visual status timeline for submitted complaints.
- **JanSahay AI Assistant**: Floating and dedicated chatbot for multilingual scheme assistance.

## Setup Instructions

1. Install dependencies:
```bash
npm install
```

2. Environment configuration:
```bash
cp .env.example .env
```

3. Run development server:
```bash
npm run dev
```
Open `http://localhost:3000` in your browser.
